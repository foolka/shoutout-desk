ШАГ 1 ИЗ 4

Приложение Twitch

В этой сборке ещё нет общего Client ID. Его можно создать один раз в Twitch. Client Secret не нужен.

  1. Войдите в Twitch и включите двухфакторную защиту, если она ещё выключена.
  2. Откройте консоль разработчика и зарегистрируйте приложение.
  3. Имя: Shoutout Desk + ваш ник. Redirect URL: http://localhost. Категория: Chat Bot. Тип клиента: Public.
  4. После создания откройте Manage, скопируйте Client ID и вставьте ниже.

Разрешите чтение чата и отправку шотаутов в своём канале. Пароль вводится только на сайте Twitch.

Для этого канала должен работать только один экземпляр автоотметок: приложение или OBS-плагин.

Подключаемся к Twitch

Проверяем авторизацию и подписку на события чата. Тестовые шотауты не отправляются.
