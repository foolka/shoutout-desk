Shoutout Desk 0.8.1

UPDATE / ОНОВЛЕННЯ / ОБНОВЛЕНИЕ

Exit the app before updating. Run the new installer, or extract the complete
ZIP over the old program folder. Never replace only the EXE.
Normal profile: %APPDATA%\Shoutout Desk
Portable.cmd profile: ShoutoutDesk-data beside the EXE.
Keep these data folders. They are not included in the distribution.
If your list looks empty, close the app first and keep a copy of the entire
old profile, not just a renamed SQLite file. Profile Review shows the expected
path and people/history counts. Restore only into a missing database. If a
working database exists, keep it and use Settings > Import for the old copy.
Use Export/Import to move people/history to another profile or PC.
Oldest versions: close the source app, back up its data folder, then import
shoutouts.sqlite in Settings after connecting the same Twitch account.
People/history/cooldowns merge without replaying pending requests.
Older releases need one manual upgrade to receive future update notifications.
Windows-protected login may require signing in again on another PC.

Перед обновлением полностью закройте приложение через Выход в трее.
Установите новую версию поверх старой или замените ВСЮ папку программы
из ZIP. Папки данных выше не удаляйте. Список, история и вход сохраняются.
Portable.cmd использует отдельный профиль: не меняйте способ запуска.
Если список выглядит пустым, закройте программу и сохраните всю прежнюю
папку данных. Не переименовывайте файлы базы и журналы SQLite вручную.
В окне проверки сверьте путь и количество записей. Если в текущей базе есть
новые записи, оставьте её и добавьте старые через «Настройки → Импорт».
Из первых версий: сохраните папку данных, подключите тот же Twitch-аккаунт
в новой версии и импортируйте shoutouts.sqlite в Настройках.

Перед оновленням закрийте програму через Вихід у треї. Встановіть нову
версію або замініть усі програмні файли з ZIP. Збережіть папки даних.
Portable.cmd використовує окремий профіль: не змінюйте спосіб запуску.
Якщо список порожній, закрийте програму і збережіть усю попередню папку.
Звірте шляхи та кількість записів. Якщо у поточній базі вже є нові записи,
залиште її та додайте старі через «Налаштування → Імпорт».
З перших версій: збережіть папку даних, підключіть той самий Twitch-акаунт
у новій версії та імпортуйте shoutouts.sqlite в Налаштуваннях.
